# Changelog

All notable changes to this project will be documented in this file. See [standard-version](https://github.com/conventional-changelog/standard-version) for commit guidelines.

## [1.2.0] - 2026-10-23

### Features

- 2025 SALN with live net worth and the official CSC form opened as a PDF
- SALN drafts show completion on the dashboard
- A phone install prompt replaces the Install App menu item
- What's New marks a version until you open it

## [1.1.0] - 2026-09-15

### Features

- Work Experience Sheet (WES) in-app rendered table and client-side PDF export
- Dynamic relational sync from PDS Work Experience section (zero duplicated fields)
- Interactive PDS selector modal to choose which PDS to relate the sheet to
- Removed "Summary of Duties" in PDS Work Experience section (now in WES)

## [1.0.0] - 2026-08-27

### Features

- Complete implementation of CS Form No. 212 (Revised 2026) Items 1–42
- Dexie.js IndexedDB schema with real-time debounced autosave
- Workbox PWA service worker with full offline precache
- Single and bundle JSON export/import + AES-256 encrypted backups
- Official 4-page government printable layout with passport photo and signature canvas
- Interactive Quick Tour and persistent tour replay
- Storage persistence check and dark mode toggle
